# NClean – Customer app

Flutter app for customers: mobile OTP sign-in, catalogue and cart, pickup address and slot, payment, order tracking.

The project is in [`laundry-user-app/`](laundry-user-app/); its README covers running it, the test APK build and the structure, and `PLAN.md` the phase-wise plan.
The backend and admin panel are on the `api-admin` branch, the delivery partner app on `driver-app`.
