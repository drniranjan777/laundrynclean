# NClean Partner – Delivery app

Flutter app for delivery partners: mobile OTP sign-in (numbers registered by a store), pickup and delivery task lists, status updates with photos, failed attempts and cash collection.

The project is in [`laundry-driver-app/`](laundry-driver-app/); its README covers running it and the test APK build, and `PLAN.md` the phase-wise plan.
The backend and admin panel are on the `api-admin` branch, the customer app on `user-app`.
